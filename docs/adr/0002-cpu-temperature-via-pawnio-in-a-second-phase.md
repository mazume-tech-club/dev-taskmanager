# コア別温度は PawnIO ドライバ経由で第 2 段に実装し、初版は管理者権限なしで動かす

Core Temp や CPU-Z が表示するコア別温度・TjMax・VID・パッケージ電力は CPU の MSR を読む必要があり、
Windows ではカーネルドライバと管理者権限が無いと取れない。それらのツールに依存する案
（共有メモリを読む）は、Core Temp が個人利用のみ無料であることと、外部ツールの起動に UAC が出ることから却下した。
自前ドライバは署名・保守・セキュリティ製品の誤検知の負担が大きく却下した。

採用: 署名済み汎用ドライバ PawnIO（GPL-2.0、LibreHardwareMonitor や FanControl が採用）を使い、
公式モジュール `IntelMSR` を IOCTL で呼んで MSR を読む。PawnIO 未インストールや管理者権限が無い環境では
ドライバ無しで取れる値（CPU Load、実クロック、ACPI 温度ゾーン）だけを表示する段階式にする。

## Consequences

- 初版はドライバ無しの範囲で出荷する。センサー取得元は差し替え可能なモジュールにしておき、第 2 段で PawnIO を足す。
- 第 2 段ではアプリ全体を管理者権限で動かす（自動起動はタスクスケジューラの最上位特権で UAC を回避）。
  MSR 読み取りだけを別サービスに分離する構成は、必要になったときの改善案として残す。
- 対応 CPU は Intel 先行。AMD は別モジュールが必要になった時点で追加する。
- PawnIO との通信は IOCTL のみで、アプリ本体のライセンスは GPL に縛られない。同梱・再配布の条件は第 2 段の着手時に確認する。
